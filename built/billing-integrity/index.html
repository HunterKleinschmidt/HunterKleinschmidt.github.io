Billing integrity pipeline

2026 · llms · statistics · dbt · python

The primary billing integrity system: it checks every timesheet submission, every weekday. An LLM classifies the free text of each note, statistical baselines compare it to the population and to the provider’s own history, and a readable rules matrix decides what gets escalated to a person. It’s a guardrail, not a ranking.

I architected it, chose its model through blind adjudication over the full history, and wrote the spec for the real-time version that catches problems before submission.
